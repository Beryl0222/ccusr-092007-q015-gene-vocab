# 跨物种基因词表治理

研究团队维护跨物种（12 物种）基因同源关系和模型输入词表的版本依据。

`fixtures/gene_mapping.json` 保存一条经过脱敏的业务样例，v1 合同读取器
（`src/contracts.js` 的 `loadRecord`）行为保持不变。治理能力以事件流实现，
新增状态通过新增事件类型演进，旧事件与旧发布快照永不改写——迁移方式见 `DESIGN.md`。

## 能力概览

- **可发布版本**：物种、基因稳定标识、别名、同源组、证据来源、有效区间组织为不可变快照（内容哈希）。
- **候选关系治理**：分片导入（乱序、幂等重试、整批校验和）→ 规则校验（错误阻断／警告须确认）→
  专家复核（理由 + 逐条确认）；循环关系检测给出环路径。
- **冲突并存**：别名重叠、同源组一对多只报告不静默选择；专家决定独立留痕，历史可追。
- **训练锁定**：启动时锁定词表版本哈希、缺失策略（error/skip/mask_token）、冲突策略与 as_of；
  同词表同策略生成逐字节一致的输入。
- **版本差异与影响标记**：新数据库发布只标出受影响实验；撤回错误来源沿依赖暂停新引用，
  旧快照与旧模型产物保留且可复现。
- **谱系溯源**：从模型槽位追到各物种原始稳定标识、别名、证据来源与选择依据。
- **项目权限**：未公开物种（如海绵）数据按项目授权可见，读路径脱敏、写路径强制。
